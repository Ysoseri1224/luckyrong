# Ruby — Design System

> 为 Ruby 与 Leif 打造的私人站点设计规范。
> 基调：中式，明艳但克制，有质感。

---

## 一、色彩

### 主色 — Ruby Red

正红，不偏冷不偏暖。锚点为 `#B22222`（CSS 内置名 `firebrick`）。

| 级别 | Hex | 用途 |
|------|-----|------|
| 50 | `#FDF2F2` | 背景 tint，极淡底色 |
| 100 | `#FADADD` | 浅色标签背景 |
| 200 | `#F4A4A4` | 禁用状态 |
| 400 | `#D94444` | 次要强调、单位文字、次要数字 |
| **600** | **`#B22222`** | **主色锚点** — 图标、强调文字、左侧竖线、勾选状态 |
| 700 | `#8E1A1A` | hover 状态 |
| 800 | `#6B1313` | 深色红文字 |
| 900 | `#470D0D` | 极深，备用 |

> 推导原则：往浅推时提高亮度、降低饱和度，色相微微偏暖（橙向）；往深推时降低亮度，色相微微偏冷（紫向）。色阶是活的，不是机械加白/加黑。

### 中性色 — 暖灰

带红色相的灰，不用纯灰（纯灰配暖红主色会显脏）。

| 级别 | Hex | 用途 |
|------|-----|------|
| 50 | `#FAF8F8` | **页面底色** |
| 100 | `#F2EEEE` | 卡片背景 |
| 200 | `#E0D8D8` | 分隔线、边框、已完成心愿文字色 |
| 400 | `#9E9090` | 辅助文字、城市名、标签、单位字 |
| 600 | `#6B5F5F` | 次要文字 |
| 800 | `#2D2424` | 正文 |
| 900 | `#1A1414` | 标题、主数字 |

### 用色原则

- 在一起天数 → 暖灰 900（陈述事实，沉稳）
- 下次见面天数 → Ruby 600（情感期待，鲜明）
- 颜色本身在传递含义，不只是装饰
- 卡片用背景色差区分层级，**不加 border**（border 是最后手段）
- 正文不用纯黑 `#000000`，用暖灰 900 `#1A1414`

## 二、字体

### 字族

| 角色 | 字族 | 说明 |
|------|------|------|
| **衬线 / 显示** | Noto Serif SC | 标题、大数字、情感性文字；专为中文优化，中英混排协调 |
| **无衬线 / 数据** | Inter | 时钟、时分秒、辅助说明、功能性文字 |

两个字族形成清晰的衬线 vs 无衬线对比（Refactoring UI：make them clearly distinct）。

### 具体分配

| 元素 | 字族 | 字号 | 字重 | 颜色 |
|------|------|------|------|------|
| 城市名（奥克兰 / 山东） | Inter | 11px | 400 | 暖灰 400 |
| 时钟数字 | Inter | 28px | 300 | 暖灰 900 |
| 「在一起」标签 | Inter | 11px | 400 | 暖灰 400 |
| 在一起天数大数字 | Noto Serif SC | 56px | 700 | 暖灰 900 |
| 「天」单位 | Noto Serif SC | 24px | 400 | 暖灰 400 |
| 在一起时分秒 | Inter | 22px | 300 | 暖灰 400 |
| 「下次见面」标签 | Inter | 11px | 400 | 暖灰 400 |
| 下次见面天数 | Noto Serif SC | 44px | 700 | Ruby 600 |
| 下次见面单位 | Noto Serif SC | 20px | 400 | Ruby 400 |
| 下次见面时分秒 | Inter | 20px | 300 | Ruby 400 |
| 模块卡片标题 | Noto Serif SC | 15px | 500 | 暖灰 900 |
| 模块卡片副标题 | Inter | 12px | 400 | 暖灰 400 |
| 心愿区块标题 | Noto Serif SC | 13px | 500 | Ruby 600 |

| 心愿列表文字（已完成） | Noto Serif SC | 14px | 400 | 暖灰 200 + strikethrough |

### 字号体系

```
11px → 标签、城市名、辅助
12px → 卡片副标题
13px → 区块标题
14px → 正文列表
15px → 卡片主标题
20px → 次要数字单位
22px → 在一起时分秒
24px → 在一起天数单位
28px → 时钟
44px → 下次见面天数
56px → 在一起天数（英雄主数字）
```

每个尺寸有明确用途，无「差不多大」的两个相邻元素。

## 三、间距

基于 4px 倍数系统：

```
4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96
```

| 值 | 用在哪 |
|----|--------|
| 4px | 元素内极小间距 |
| 8px | 标签与内容之间 |
| 12px | 卡片之间的 gap |
| 16px | 卡片内部 padding |
| 20px | 心愿列表项间距 |
| 24px | 大区块之间（模块区到心愿区） |
| 28px | 英雄区内，在一起与下次见面之间 |
| 32px | 桌面端左右分栏 gap |
| 48px | 时钟区到英雄区 |

## 四、布局

### 设计稿基准

**移动端优先**，桌面端是延伸。最大宽度 **680px 居中**，不铺满屏幕——留白是设计本身。

### 移动端（单列）

```
时钟条（页眉，无卡片边框）
  ↓ 48px
英雄区
  在一起天数（主）
  下次见面天数（次，ruby 红）
  ↓ 底部分隔线
Timeline 预览（可折叠）
  竖向时间线 + 72px 真实相片 + 日期与可选摘要
  ↓ 48px
心愿清单（裸列，左侧 ruby 红竖线）
  ↓ 40px
模块入口（无标题，直接显示）
  Together Time
  CET6 Camp
```

### 桌面端（≥ 580px，双列）

```
时钟条（左奥克兰，右山东，两端对齐）
  ↓ 48px
┌─────────────────┬─────────────────┐
│  英雄区          │  心愿清单        │
│  在一起 56px     │                 │
│  下次见面 44px   │  模块入口        │
│                 │  Together Time  │
│  Timeline 预览   │  CET6 Camp      │
└─────────────────┴─────────────────┘
```

桌面端左列占七份、右列占五份，中间保留 40px 空隙；Timeline 留在左列承接英雄区，心愿与模块入口在右列。Timeline 在桌面端始终展开，折叠箭头只在移动端显示；模块入口不设标题或折叠层。

### 组件规则

- **时钟** — 页眉条，无背景无边框，左奥克兰右山东
- **英雄区** — 无卡片包裹，数字直接浮在页面上
- **Timeline 预览** — 一条暖灰细线串联节点；按日期倒序显示 2026 年 7 月、2 月和 1 月的真实相片，重点节点使用 Ruby 600，预览记录点击进入 `/timeline/`
- **模块卡片** — 单列排列，背景暖灰 100，无 border，10px 圆角，hover 加深至暖灰 200
- **心愿清单** — 无卡片，左侧 2px Ruby 600 竖线，列表项底部 1px 暖灰 200 分隔线

## 五、视觉层级原则

来自 Refactoring UI：

1. **三层文字颜色**：主要内容暖灰 900，次要内容暖灰 400，辅助信息暖灰 200。三层够了。
2. **颜色传递含义**：在一起用深色（事实），下次见面用 ruby 红（期待）。颜色不只是装饰。
3. **边框是最后手段**：优先用背景色差区分区域，实在需要区分再加 border。
4. **间距要夸张**：比「够了」再大 50%，留白本身有克制感。
5. **不用纯黑**：正文和标题用暖灰 900 `#1A1414`，与主色色相协调。

## 六、已实现的原型

`design/ruby-prototype.html` 是当前视觉与结构参考，包含完整 token、字体引入、响应式布局、Timeline 预览和实时时钟逻辑。业务实现保留生产所需的真实路由、正确时区和日期设置能力，不照搬原型中的简化逻辑。

## 七、首页实现基线

主路由 `/` 使用 Bridgetown 2.x 生成静态 HTML，不再由 Astro 生成。Bridgetown 负责 ERB 布局、首页模板、Timeline 预览、模块入口和心愿数据；实时钟表、计时器、日期设置弹窗、折叠和勾选状态仍由浏览器端 JavaScript 负责。

- 页面模板：`src/index.html.erb`
- 布局：`src/_layouts/default.erb`
- 页面数据：`src/_data/modules.yml`、`src/_data/wishes.yml`、`src/_data/timeline_preview.yml`
- 样式与交互：`src/assets/ruby.css`、`src/assets/ruby.js`
- 构建输出：`output/`
- 生产构建：`bundle exec bridgetown build`

现有 Cloudflare Worker 继续负责 `/together/`、`/cet6/` 和 `/timeline/` 的转发；本次迁移只替换根首页的生成器。

在一起计时以 `2026-01-25 21:36:00 UTC+8` 为起点。下次见面的默认日期为 2026-12-11，用户可在首页修改并保存在本机。
